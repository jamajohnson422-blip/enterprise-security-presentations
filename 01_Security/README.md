# Securing Data in SCM, CRM, and ERP Systems

## Project Overview

This project examines cybersecurity and data protection considerations across Supply Chain Management (SCM), Customer Relationship Management (CRM), and Enterprise Resource Planning (ERP) systems.

The project evaluates security risks associated with interconnected enterprise systems and presents strategies organizations can use to protect sensitive business and customer information while maintaining secure business operations.

## Business Scenario

The analysis was developed for a simulated organization, ABC Company, to evaluate how enterprise data can be protected across SCM, CRM, and ERP environments.

The project focuses on identifying security concerns and recommending controls designed to reduce organizational risk.
